3. Probabilitas Dasar

Peluang P(A) adalah angka 0–1 yang menyatakan seberapa mungkin kejadian A terjadi. Untuk semua kemungkinan hasil, total peluangnya = 1.

Peluang bersyarat

P(A | B) = P(A ∩ B) / P(B)

"Peluang A, jika kita sudah tahu B terjadi". Di RL hampir semuanya bersyarat: π(a|s) = peluang memilih aksi a jika berada di state s, dan P(s'|s,a) = peluang tiba di s' jika melakukan a di s. Syaratnya: Σa π(a|s) = 1 untuk setiap s.

Aturan perkalian & peluang trajektori

Peluang beberapa kejadian berurutan = perkalian peluang bersyaratnya: P(A,B) = P(A)·P(B|A). Berkat sifat Markov, peluang satu trajektori τ = (s0, a0, s1, a1, …) menjadi:

P(τ) = p(s0) · Πt π(at|st) · P(st+1|st,at)

Bagian biru dikendalikan agen, bagian oranye dikendalikan lingkungan. Rumus ini adalah kunci penurunan policy gradient di bagian 9.

📝 Contoh Robot di state "dekat pintu". π(buka|dekat pintu) = 0.8. Jika membuka, pintu terbuka dengan peluang 0.9 (kadang macet). Peluang "memilih buka dan pintu terbuka" = 0.8 × 0.9 = 0.72.

Independensi & sifat Markov

A dan B independen jika P(A|B) = P(A): mengetahui B tidak mengubah apa pun. Sifat Markov adalah independensi bersyarat: jika state sekarang diketahui, masa lalu tidak menambah informasi.

P(st+1 | st, at, st−1, at−1, …) = P(st+1 | st, at)

Teorema Bayes

P(H | D) = P(D | H) · P(H) / P(D)

Memperbarui keyakinan tentang hipotesis H setelah melihat data D. Di RL dipakai pada Thompson sampling dan Bayesian RL: "seberapa yakin saya bahwa mesin slot B adalah yang terbaik, setelah melihat 10 tarikan?"

✍️ Contoh hitung manual: Bayes

Sebuah mesin slot bisa bertipe bagus (peluang menang 0,7) atau biasa (peluang menang 0,4). Awalnya kita 50:50 tidak tahu. Kita tarik sekali dan menang. Seberapa yakin sekarang bahwa mesin itu bagus?

  1. Peluang menang jika bagus × prior: 0,7 × 0,5 = 0,35
  2. Peluang menang jika biasa × prior: 0,4 × 0,5 = 0,20
  3. Total peluang menang: P(menang) = 0,35 + 0,20 = 0,55
  4. P(bagus | menang) = 0,35 / 0,55 ≈ 0,636

Satu kemenangan menaikkan keyakinan dari 50% menjadi 63,6%. Setiap tarikan berikutnya memperbarui angka ini lagi. Inilah cara kerja Thompson sampling.

4. Ekspektasi & Variansi

Ekspektasi (nilai harapan) adalah rata-rata tertimbang semua kemungkinan nilai, dengan bobot berupa peluangnya:

𝔼[X] = Σx x · p(x)     (kontinu: ∫ x p(x) dx)

Contoh dadu: 𝔼[X] = (1+2+3+4+5+6)/6 = 3,5, padahal dadu tidak pernah menghasilkan 3,5. Ekspektasi adalah rata-rata jangka panjang, bukan hasil yang "diharapkan muncul".

Variansi mengukur seberapa menyebar hasilnya di sekitar ekspektasi:

Var[X] = 𝔼[ (X − 𝔼[X])² ] = 𝔼[X²] − 𝔼[X]²

✍️ Contoh hitung manual: variansi dadu

  1. 𝔼[X] = (1 + 2 + 3 + 4 + 5 + 6) / 6 = 21 / 6 = 3,5
  2. 𝔼[X²] = (1 + 4 + 9 + 16 + 25 + 36) / 6 = 91 / 6 ≈ 15,167
  3. Var[X] = 𝔼[X²] − 𝔼[X]² = 15,167 − 3,5² = 15,167 − 12,25 ≈ 2,917
  4. Standar deviasi = √2,917 ≈ 1,71: rata-rata, hasil lemparan menyimpang sekitar 1,7 dari 3,5.

Angka 3,5 dan 2,92 inilah yang ditampilkan sebagai "Teori" di demo berikut.

Sifat-sifat penting

  • Linearitas: 𝔼[aX + bY] = a𝔼[X] + b𝔼[Y], selalu berlaku, bahkan jika X dan Y tidak independen. Inilah yang membuat 𝔼[r + γG'] = 𝔼[r] + γ𝔼[G'].
  • Variansi dari jumlah: Var[X+Y] = Var[X] + Var[Y] jika independen. Return Monte Carlo menjumlahkan banyak reward acak, sehingga variansinya besar.
  • Hukum total ekspektasi: 𝔼[X] = 𝔼Y[ 𝔼[X | Y] ]. Ekspektasi bisa dihitung bertahap, "cabang demi cabang". Ini persis struktur persamaan Bellman.

Bellman = ekspektasi bertingkat

Softmax: mengubah skor menjadi peluang

Neural network mengeluarkan skor sembarang (logit) z1..K. Softmax mengubahnya menjadi peluang yang positif dan totalnya 1:

softmax(z)i = ezi/τ / Σj ezj/τ

Sigmoid: softmax untuk dua pilihan

σ(x) = 1 / (1 + e−x)

Mengubah selisih skor menjadi peluang 0–1. Reward model di RLHF memakai σ(rw − rl) sebagai peluang jawaban w lebih disukai daripada l (model Bradley–Terry). Softmax dua kelas dengan logit (x, 0) persis sama dengan σ(x).

✍️ Contoh: jawaban A mendapat skor 2,0 dan jawaban B mendapat 0,5, sehingga selisihnya 1,5. σ(1,5) = 1 / (1 + e−1,5) = 1 / (1 + 0,223) ≈ 0,818. Jadi model memperkirakan 81,8% manusia akan lebih menyukai A.

6. Estimasi, Bias & Variansi

Di RL kita hampir tidak pernah tahu nilai sebenarnya, kita hanya memperkirakan-nya dari sampel. Sebuah estimator θ̂ untuk besaran θ dinilai dengan dua hal:

🎯 Bias𝔼[θ̂] − θ. Apakah estimator rata-ratanya tepat sasaran? Contoh: TD target bias karena memakai tebakan V(s') yang belum akurat.
🎲 VariansiVar[θ̂]. Seberapa "berisik" estimator dari sampel ke sampel? Contoh: return Monte Carlo tidak bias, tetapi variansinya tinggi.
Error kuadrat rata-rata (MSE) = Bias² + Variansi

Inilah alasan matematis di balik banyak pilihan desain di RL: TD vs MC, nilai n pada n-step, λ pada GAE, dan baseline. Semuanya mengatur trade-off bias–variansi.

✍️ Contoh hitung manual: dua estimator, MSE sama

Nilai sebenarnya θ = 10. Dua estimator dicoba 4 kali:

A (berisik)9, 11, 9, 11100((−1)² + 1² + (−1)² + 1²)/4 = 10 + 1 = 1
B (meleset konsisten)11, 11, 11, 1111+101 + 0 = 1

A mirip Monte Carlo (tepat rata-ratanya, tetapi berisik), B mirip TD (stabil, tetapi bias). Errornya sama besar, hanya sumbernya berbeda.

Rata-rata berjalan (incremental mean)

Rata-rata n sampel bisa dihitung tanpa menyimpan semua sampel:

Qn = Qn−1 + (1/n) · ( xn − Qn−1 )

Jika 1/n diganti konstanta α, didapat exponential moving average (EMA): sampel lama "dilupakan" secara eksponensial dengan bobot (1−α)k. Ini adalah bentuk update Q-Learning dan TD: Q ← Q + α(target − Q). EMA penting karena di RL target terus berubah (non-stationary) seiring policy membaik.

Demo: rata-rata 1/n vs EMA dengan α tetap

Data acak dengan rata-rata sebenarnya 2, lalu tiba-tiba berubah menjadi 5 di langkah ke-100 (seperti nilai Q yang berubah saat policy membaik).

• titik = sampel, ━ oranye = rata-rata 1/n, ━ biru = EMA α, ┅ hijau = nilai sebenarnya. Rata-rata 1/n sangat lambat beradaptasi setelah perubahan. α besar cepat beradaptasi tetapi berisik (variansi tinggi), α kecil halus tetapi lambat (bias sementara).

✍️ Contoh hitung manual: 1/n vs EMA

Data masuk berurutan: 2, 2, 5, 5 (nilai sebenarnya berubah dari 2 menjadi 5 di data ke-3). Estimasi awal 0, EMA memakai α = 0,5:

7. Deret Geometri & Diskon

Return terdiskon adalah deret geometri. Jika reward konstan r di setiap langkah tanpa akhir:

G = r + γr + γ²r + … = r · Σk=0∞ γk = r / (1 − γ)    (untuk 0 ≤ γ < 1)

Dua konsekuensi penting:

  • Return selalu terbatas: jika |r| ≤ Rmax, maka |G| ≤ Rmax/(1−γ). Tugas tanpa akhir pun punya nilai yang terdefinisi.
  • Horizon efektif ≈ 1/(1−γ): kira-kira sejauh itulah agen "melihat ke depan".
γHorizon efektif 1/(1−γ)Bobot reward 100 langkah lagi (γ100)
0,910 langkah0,00003
0,99100 langkah0,366
0,9991000 langkah0,905

✍️ Cek manual: reward 1 tiap langkah dengan γ = 0,9 seharusnya total 1/(1 − 0,9) = 10. Jumlah parsialnya: 1 langkah = 1; 2 langkah = 1 + 0,9 = 1,9; 3 langkah = 1,9 + 0,81 = 2,71; 10 langkah ≈ 6,51; 50 langkah ≈ 9,95. Jumlahnya memang terus mendekati 10 tetapi tidak pernah melewatinya.

Bentuk rekursif & kontraksi

Deret ini bisa ditulis rekursif: Gt = rt+1 + γGt+1. Itulah asal-usul persamaan Bellman. Selain itu, setiap iterasi Bellman memperkecil error paling sedikit dengan faktor γ (kontraksi):

‖Vk − V*‖ ≤ γk · ‖V0 − V*‖

Untuk mengecilkan error 1000 kali dengan γ = 0,9 dibutuhkan sekitar k = ln(0,001)/ln(0,9) ≈ 66 iterasi, sedangkan dengan γ = 0,99 butuh ≈ 688 iterasi. Itu sebabnya value iteration lebih lambat konvergen untuk γ besar (coba di demo modul Intermediate).

8. Kalkulus & Gradient Descent

Turunan f'(x) adalah kemiringan fungsi di titik x: seberapa cepat f berubah jika x digeser sedikit. Jika fungsi punya banyak input θ = (θ1, …, θn), turunan terhadap masing-masing input disebut turunan parsial, dan vektornya disebut gradien:

∇θf = ( ∂f/∂θ1, ∂f/∂θ2, …, ∂f/∂θn )

Gradien menunjuk ke arah kenaikan tercepat. Untuk meminimalkan loss, melangkahlah berlawanan arah gradien (gradient descent). Untuk memaksimalkan return, ikuti arah gradien (gradient ascent, seperti di policy gradient):

θ ← θ − α ∇θL(θ)    (descent)      θ ← θ + α ∇θJ(θ)    (ascent)

Coba: (1) x awal = 1,8 berakhir di minimum lokal kanan, sedangkan x awal = −0,5 berakhir di minimum global kiri. (2) α = 1,0 atau lebih: langkah terlalu besar sehingga terlempar bolak-balik atau divergen. Inilah kenapa learning rate sangat penting di DQN dan PPO.

Untuk fungsi di demo, satu langkah dari x = 1,8 dengan α = 0,1: f'(1,8) = 1,8³ − 2(1,8) + 0,3 = 2,532, sehingga x baru = 1,8 − 0,2532 = 1,547.

Aturan rantai

Jika y = f(g(x)), maka dy/dx = f'(g(x)) · g'(x). Neural network adalah komposisi banyak fungsi, dan backpropagation hanyalah aturan rantai yang diterapkan berulang dari output ke input. PyTorch melakukannya otomatis lewat loss.backward().

✍️ Contoh: y = (3x + 1)² di x = 2. Pecah menjadi g = 3x + 1 = 7 dan y = g². Turunan lokal: dy/dg = 2g = 14 dan dg/dx = 3. Dikalikan: dy/dx = 14 × 3 = 42. Backprop bekerja persis seperti ini: setiap "mata rantai" menghitung turunannya sendiri, lalu hasilnya dikalikan berurutan.

📝 Contoh: gradien loss DQN L(θ) = (y − Qθ)², dengan target y dianggap konstan. Aturan rantai: ∇θL = −2(y − Qθ) · ∇θQθ. Gradient descent dengan langkah α/2 memberi θ ← θ + α(y − Qθ)∇θQθ, persis update semi-gradient di modul Intermediate. Untuk tabel (Q-table), ∇θQ bernilai 1 di sel (s,a) dan 0 di tempat lain, sehingga kembali menjadi rumus Q-Learning biasa.

9. Logaritma & Log-Derivative Trick

Sifat logaritma natural (ln) yang paling sering dipakai:

SifatKegunaan di RL / ML
log(ab) = log a + log bMengubah perkalian peluang trajektori menjadi penjumlahan, lebih stabil secara numerik
log(a/b) = log a − log bRasio PPO dihitung sebagai exp(logp_baru − logp_lama)
d/dx log x = 1/xDasar log-derivative trick
log monoton naikMemaksimalkan p sama dengan memaksimalkan log p

✍️ Contoh: peluang sebuah trajektori = 0,8 × 0,9 × 0,5 = 0,36. Dengan log: ln 0,8 + ln 0,9 + ln 0,5 = −0,223 − 0,105 − 0,693 = −1,022, dan memang ln 0,36 = −1,022. Untuk episode 1000 langkah, perkalian peluang bisa menjadi sekecil 10−300 dan "habis" di komputer (underflow), sedangkan jumlah log tetap angka biasa. Karena itu kode RL dan LLM selalu bekerja dengan log_prob.

Log-derivative trick, langkah demi langkah

Kita ingin gradien dari J(θ) = 𝔼x∼pθ[f(x)] = Σx pθ(x) f(x):

  1. Masukkan gradien ke dalam jumlahan: ∇J = Σx ∇pθ(x) · f(x).
  2. Dari aturan rantai, ∇ log p = ∇p / p, sehingga ∇p = p · ∇ log p.
  3. Substitusi: ∇J = Σx pθ(x) · ∇ log pθ(x) · f(x) = 𝔼x∼pθ[ ∇ log pθ(x) · f(x) ].
  4. Bentuknya kembali menjadi ekspektasi, sehingga bisa diperkirakan dengan sampel (Monte Carlo) tanpa perlu menjumlahkan semua kemungkinan.
  5. Untuk trajektori, log P(τ) = log p(s0) + Σ log πθ(at|st) + Σ log P(st+1|…). Hanya suku π yang bergantung pada θ, sehingga dinamika lingkungan hilang dari gradien.

Untuk policy softmax dengan parameter θ (satu logit per aksi), gradiennya sangat sederhana:

∇θ log πθ(a) = onehot(a) − πθ

Contoh: π = (0,2; 0,5; 0,3) dan aksi terpilih a = 1 (indeks ke-2). Gradiennya (0 − 0,2; 1 − 0,5; 0 − 0,3) = (−0,2; 0,5; −0,3): naikkan logit aksi terpilih, turunkan yang lain. Rumus inilah yang dipakai demo REINFORCE di modul Advanced.

10. Aljabar Linear Secukupnya

VektorDaftar angka, misalnya state CartPole s = (posisi, kecepatan, sudut, kecepatan sudut) ∈ ℝ⁴.
Dot productu·v = Σi uivi. Mengukur "kemiripan arah". Dipakai di linear function approximation dan attention.
MatriksTabel angka. Perkalian matriks–vektor Wx adalah inti setiap layer neural network: y = σ(Wx + b).

✍️ Contoh hitung manual: dot product & perkalian matriks

  • Dot product: (1, 2, 3) · (4, 0, −1) = 1×4 + 2×0 + 3×(−1) = 4 + 0 − 3 = 1
  • Matriks × vektor: W = [[1 2] [0 −1]] dan x = (3, 1). Setiap baris W di-dot dengan x: baris 1: 1×3 + 2×1 = 5, baris 2: 0×3 + (−1)×1 = −1, sehingga Wx = (5, −1).

Satu layer neural network dengan 1000 neuron hanyalah 1000 dot product seperti ini yang dihitung serentak di GPU.

Linear function approximation

Q̂(s,a; θ) = θ⊤φ(s,a) = Σi θi φi(s,a)   ⇒   ∇θQ̂ = φ(s,a)

Gradien fungsi linear adalah vektor fiturnya sendiri, jadi update-nya sangat murah. Q-table adalah kasus khusus dengan φ berupa vektor one-hot.

Persamaan Bellman dalam bentuk matriks

Untuk policy tetap dengan n state, tulis V dan R sebagai vektor dan P sebagai matriks transisi n×n. Persamaan Bellman menjadi:

V = R + γPV   ⇒   V = (I − γP)−1 R
📝 Contoh 2 state (γ = 0,9) State A: reward 1, lalu ke A atau B dengan peluang 0,5/0,5. State B: reward 0, lalu ke A 0,2 dan tetap di B 0,8.
P = [[0,5 0,5] [0,2 0,8]], R = (1, 0). Maka I − γP = [[0,55 −0,45] [−0,18 0,28]], determinannya 0,55·0,28 − 0,45·0,18 = 0,073, sehingga
V(A) = 0,28/0,073 ≈ 3,836 dan V(B) = 0,18/0,073 ≈ 2,466.
Cek: V(A) = 1 + 0,9·(0,5·3,836 + 0,5·2,466) = 1 + 0,9·3,151 ≈ 3,836 ✓

Invers matriks butuh waktu ∼n³, sehingga tidak praktis untuk jutaan state. Karena itu dipakai iterasi (DP) atau sampel (TD). Kode di bagian 12 membandingkan keduanya.

11. Entropi & KL Divergence

Entropi mengukur ketidakpastian (keacakan) sebuah distribusi:

ℋ(p) = −Σx p(x) log p(x)

Entropi = 0 jika hasilnya pasti, dan maksimum (log K) jika semua K hasil sama mungkin. SAC dan PPO memberi bonus entropi agar policy tidak terlalu cepat menjadi deterministik.

KL divergence mengukur seberapa berbeda distribusi p dari q:

KL(p ‖ q) = Σx p(x) log ( p(x) / q(x) )  ≥ 0
  • KL = 0 jika dan hanya jika p = q.
  • Tidak simetris: KL(p‖q) ≠ KL(q‖p), jadi bukan "jarak" dalam arti biasa.
  • Hubungan dengan cross-entropy: ℋ(p,q) = ℋ(p) + KL(p‖q). Loss klasifikasi yang biasa dipakai di deep learning adalah cross-entropy.

✍️ Contoh hitung manual: entropi & KL dua koin

Koin p: muncul "gambar" dengan peluang 0,5. Koin q: peluang 0,8.

  1. ℋ(p) = −(0,5 ln 0,5 + 0,5 ln 0,5) = −ln 0,5 = 0,693 (maksimum, paling tidak pasti)
  2. ℋ(q) = −(0,8 ln 0,8 + 0,2 ln 0,2) = −(−0,179 − 0,322) = 0,500 (lebih pasti)
  3. KL(p‖q) = 0,5 ln(0,5/0,8) + 0,5 ln(0,5/0,2) = 0,5 × (−0,470) + 0,5 × 0,916 = 0,223
  4. KL(q‖p) = 0,8 ln(0,8/0,5) + 0,2 ln(0,2/0,5) = 0,8 × 0,470 + 0,2 × (−0,916) = 0,193

Dua langkah terakhir memberi angka berbeda, bukti bahwa KL tidak simetris. Ini adalah nilai awal demo di bawah, jadi kamu bisa langsung mencocokkannya.

🔗 Di mana KL dipakai TRPO: batasi KL(πlama‖πbaru) ≤ δ. PPO: KL aproksimasi dipantau sebagai sinyal kesehatan training. RLHF: penalti β·KL(πθ‖πref) agar LLM tidak menyimpang jauh dari model awal. DPO: turunan langsung dari objektif RLHF dengan KL tersebut.

12. Praktik dengan NumPy

Satu skrip untuk memverifikasi konsep-konsep di modul ini dengan angka. Hanya butuh numpy.

import numpy as np
rng = np.random.default_rng(0)

# 1) Hukum bilangan besar: rata-rata sampel -> ekspektasi
dadu = rng.integers(1, 7, size=10_000)
for n in [10, 100, 1_000, 10_000]:
    print(f"n = {n:6d} | rata-rata dadu = {dadu[:n].mean():.3f} (teori 3.5)")

# 2) Bellman bentuk matriks vs iterasi (contoh 2 state di bagian 10)
P = np.array([[0.5, 0.5], [0.2, 0.8]])
R = np.array([1.0, 0.0])
gamma = 0.9
V_tepat = np.linalg.solve(np.eye(2) - gamma * P, R)     # V = (I - γP)^-1 R
V = np.zeros(2)
for k in range(200):
    V = R + gamma * P @ V                                 # iterasi Bellman
print("\nV tepat   :", V_tepat.round(3))
print("V iterasi :", V.round(3))

# 3) Gradien log-softmax: rumus analitik vs turunan numerik
def softmax(z):
    e = np.exp(z - z.max())
    return e / e.sum()

theta, a, h = np.array([0.5, 1.0, -0.3]), 1, 1e-6
analitik = np.eye(3)[a] - softmax(theta)                 # onehot(a) - π
numerik = np.array([(np.log(softmax(theta + h * e)[a]) -
                     np.log(softmax(theta - h * e)[a])) / (2 * h) for e in np.eye(3)])
print("\ngradien analitik:", analitik.round(4))
print("gradien numerik :", numerik.round(4))

# 4) Estimator policy gradient (score function): tanpa vs dengan baseline
r = np.array([5.0, 6.0, 5.5])                             # reward tiap aksi
pi = softmax(theta)
grad_benar = sum(pi[i] * r[i] * (np.eye(3)[i] - pi) for i in range(3))
acts = rng.choice(3, size=100_000, p=pi)
score = np.eye(3)[acts] - pi                              # ∇ log π(a)
g0 = r[acts, None] * score                                # tanpa baseline
g1 = (r[acts] - pi @ r)[:, None] * score                  # baseline = 𝔼[r]
print("\ngradien sebenarnya :", grad_benar.round(3))
print("tanpa baseline     :", g0.mean(0).round(3), "| variansi total", g0.var(0).sum().round(3))
print("dengan baseline    :", g1.mean(0).round(3), "| variansi total", g1.var(0).sum().round(3))

# 5) Entropi & KL divergence
def entropi(p):
    return -np.sum(p * np.log(p))

def kl(p, q):
    return np.sum(p * np.log(p / q))

p, q = np.array([0.7, 0.2, 0.1]), np.full(3, 1 / 3)
print(f"\nH(p) = {entropi(p):.3f} | H(q) = {entropi(q):.3f} (maks ln 3 = {np.log(3):.3f})")
print(f"KL(p||q) = {kl(p, q):.3f} | KL(q||p) = {kl(q, p):.3f}  -> tidak simetris")
