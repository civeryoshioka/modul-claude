1. Apa itu Reinforcement Learning?

Reinforcement Learning (RL) adalah cabang machine learning di mana sebuah agen belajar mengambil keputusan dengan cara mencoba-coba (trial and error) di dalam sebuah lingkungan. Setiap tindakan memberi umpan balik berupa reward (hadiah) atau penalti. Tujuan agen: memaksimalkan total reward dalam jangka panjang.

🐶 Analogi: melatih anjing Kamu bilang "duduk". Kalau anjing duduk, ia dapat camilan (reward positif). Kalau tidak, tidak dapat apa-apa. Lama-kelamaan anjing belajar bahwa "duduk saat mendengar perintah" = camilan. Kamu tidak pernah menjelaskan caranya — anjing menemukannya sendiri dari pengalaman. Itulah inti RL.

2. Komponen Utama

Semua masalah RL bisa digambarkan sebagai siklus interaksi antara agen dan lingkungan yang berulang di setiap langkah waktu t:

Agen (Agent)Si pembuat keputusan. Contoh: pemain game, robot, program trading.
Lingkungan (Environment)Semua hal di luar agen yang merespons aksinya. Contoh: papan catur, jalan raya.
State (s)Gambaran situasi saat ini. Contoh: posisi semua bidak di papan.
Aksi (a)Pilihan yang bisa dilakukan agen. Contoh: atas, bawah, kiri, kanan.
Reward (r)Angka umpan balik setelah aksi. Positif = bagus, negatif = buruk.
Policy (π)"Otak" agen: aturan yang memetakan state → aksi. Inilah yang ingin kita pelajari.
📝 Policy deterministik vs stokastik Deterministik: π(s) = a — di state s selalu pilih aksi a.
Stokastik: π(a|s) = peluang memilih aksi a di state s, misalnya 70% kanan, 30% atas.

Satu rangkaian interaksi dari awal sampai selesai (misalnya satu ronde game) disebut episode. Urutan yang dihasilkan: s₀, a₀, r₁, s₁, a₁, r₂, s₂, … sampai state terminal (menang/kalah/selesai).

3. Reward & Return

Agen tidak sekadar mengejar reward sesaat, tetapi total reward ke depan yang disebut return (G). Karena reward masa depan lebih tidak pasti, kita memberinya bobot lebih kecil dengan discount factor γ (gamma), 0 ≤ γ ≤ 1:

Gt = rt+1 + γ·rt+2 + γ²·rt+3 + … = Σk=0∞ γk·rt+k+1
  • γ mendekati 0 → agen "rabun jauh", hanya peduli reward sekarang.
  • γ mendekati 1 → agen "visioner", menghargai reward masa depan hampir sama dengan sekarang.

Coba sendiri: pengaruh γ

Skenario: agen mendapat reward +1 di setiap langkah 0–8, lalu +10 di langkah 9. Batang = bobot γk tiap langkah.

Return total G = · Nilai reward +10 di akhir tinggal

✍️ Contoh hitung manual: return

Sebuah episode berlangsung 3 langkah. Agen mendapat reward −1, −1, lalu +10 (sampai di tujuan). Dengan γ = 0.9, berapa return dari awal (G0)?

Cara 1: jumlahkan langsung. Kalikan setiap reward dengan bobot γk, lalu jumlahkan:

Langkah kReward rk+1Bobot γkγk × r
0−10.9⁰ = 1−1
1−10.9¹ = 0.9−0.9
2+100.9² = 0.81+8.1
Total G06.2

Cara 2: hitung mundur dari akhir dengan rumus rekursif Gt = rt+1 + γ · Gt+1:

  1. Langkah terakhir: G2 = 10 (tidak ada reward lagi setelahnya).
  2. G1 = −1 + 0.9 × 10 = 8
  3. G0 = −1 + 0.9 × 8 = 6.2 → hasilnya sama dengan cara 1.

Cara mundur ini lebih hemat, karena setiap langkah cukup memakai hasil langkah sesudahnya. Ide inilah yang nanti menjadi persamaan Bellman di bagian 6. Sebagai perbandingan, dengan γ = 0.5 hasilnya G0 = −1 − 0.5 + 0.25 × 10 = 1.0, dan dengan γ = 0 hanya −1. Makin kecil γ, makin kecil arti hadiah +10 di masa depan.

⚠️ Hati-hati merancang reward Agen akan mengoptimalkan persis apa yang kamu beri reward, bukan apa yang kamu maksud. Contoh terkenal: agen balap perahu yang diberi poin untuk menabrak target malah berputar-putar mengumpulkan poin tanpa pernah menyelesaikan lomba. Fenomena ini disebut reward hacking.

4. Eksplorasi vs Eksploitasi

Bayangkan kamu baru pindah ke kota baru. Kamu sudah menemukan satu warung makan yang enak. Apakah kamu terus makan di sana (eksploitasi — memakai pengetahuan terbaik saat ini), atau mencoba warung lain yang mungkin lebih enak (eksplorasi — mencari informasi baru)?

Agen RL selalu menghadapi dilema ini. Terlalu banyak eksploitasi → terjebak pada pilihan "lumayan". Terlalu banyak eksplorasi → buang waktu pada pilihan buruk.

Strategi ε-greedy

Solusi paling sederhana: dengan peluang ε (epsilon) pilih aksi acak, sisanya (1 − ε) pilih aksi dengan nilai tertinggi saat ini.

aksi = { acak, dengan peluang ε  ;  argmaxa Q(a), dengan peluang 1 − ε }

Demo: Multi-Armed Bandit (3 mesin slot)

Setiap mesin punya peluang menang (reward 1) yang tersembunyi. Agen harus menebak mana yang terbaik hanya dari mencoba.

Total tarikan: 0 · Total reward: 0 · Rata-rata: 0.00 · Memilih mesin terbaik: 0%

💡 Coba ε = 0 (tanpa eksplorasi) lalu reset beberapa kali — agen sering terjebak di mesin yang bukan terbaik.

Estimasi nilai tiap mesin diperbarui dengan rata-rata berjalan (incremental mean):

Q(a) ← Q(a) + (1/N(a)) · [ r − Q(a) ]

Pola "nilai lama + langkah × (target − nilai lama)" ini akan muncul lagi di Q-Learning. Ingat baik-baik!

✍️ Contoh hitung manual: estimasi nilai mesin

Mesin A ditarik 4 kali dan memberi reward 1, 0, 1, 1. Estimasi awal Q(A) = 0. Kita update setelah setiap tarikan:

Tarikan ke-nReward rQ lamaHitungan Q lama + (1/n)(r − Q lama)Q baru
1100 + (1/1)(1 − 0)1
2011 + (1/2)(0 − 1)0.5
310.50.5 + (1/3)(1 − 0.5)0.667
410.6670.667 + (1/4)(1 − 0.667)0.75

Cek: rata-rata biasa (1 + 0 + 1 + 1) / 4 = 0.75, hasilnya sama. Bedanya, rumus berjalan tidak perlu menyimpan semua reward lama.

Peluang ε-greedy. Misalkan sekarang Q(A) = 0.75, Q(B) = 0.6, Q(C) = 0 (belum pernah dicoba), dengan ε = 0.1:

  1. Dengan peluang 1 − ε = 0.9, agen mengeksploitasi dan memilih A (Q tertinggi).
  2. Dengan peluang ε = 0.1, agen memilih acak dari 3 mesin, jadi tiap mesin mendapat 0.1 / 3 ≈ 0.033.
  3. Total: P(A) = 0.9 + 0.033 = 0.933, P(B) = 0.033, P(C) = 0.033.

Tanpa eksplorasi (ε = 0), mesin C tidak akan pernah dicoba, padahal bisa saja C yang terbaik. Itulah kenapa ε > 0 penting.

5. Markov Decision Process (MDP)

Untuk membahas RL secara rapi, masalahnya dirumuskan sebagai MDP, yaitu lima komponen:

MDP = ( S, A, P, R, γ )
SimbolNamaArti
SState spaceHimpunan semua state yang mungkin
AAction spaceHimpunan semua aksi yang mungkin
P(s'|s,a)TransisiPeluang pindah ke s' jika melakukan aksi a di state s
R(s,a)Fungsi rewardReward yang diterima
γDiscount factorSeberapa penting masa depan

Sifat Markov

"Masa depan hanya bergantung pada masa kini, bukan pada sejarah bagaimana kita sampai di sini."

♟️ Contoh Dalam catur, posisi bidak saat ini sudah cukup untuk menentukan langkah terbaik — tidak perlu tahu urutan langkah sebelumnya. Jadi posisi papan memenuhi sifat Markov. Sebaliknya, satu frame foto bola tidak memberi tahu arah geraknya; kita butuh beberapa frame agar state-nya Markov.

Contoh MDP mini: Mahasiswa

Main game memberi reward kecil sekarang (+1), tapi membawa ke state "Lelah". Belajar memberi reward besar (+10). Agen dengan γ yang cukup besar akan belajar memilih "belajar".

✍️ Contoh hitung manual: membandingkan policy

Mulai dari state Segar dengan γ = 0.9. Kita hitung return dari tiga policy berbeda:

PolicyUrutan rewardHitungan returnReturn
① Langsung belajar+101010
② Main game, tidur, lalu belajar+1, 0, +101 + 0.9 × 0 + 0.81 × 109.1
③ Main game & tidur terus+1, 0, +1, 0, …1 + 0.81 + 0.81² + … = 1 / (1 − 0.81)5.26

Policy ① paling baik, jadi agen yang optimal memilih belajar di state Segar. (Baris ③ memakai rumus deret geometri: 1 + x + x² + … = 1/(1 − x) dengan x = 0.9² = 0.81.)

⚠️ Jebakan γ = 1 Tanpa diskon (γ = 1), policy ③ bernilai 1 + 0 + 1 + 0 + … = tak hingga, sehingga mengalahkan policy ① yang hanya 10. Agen akan main game selamanya dan tidak pernah lulus. Contoh kecil ini menunjukkan kenapa γ < 1 dan desain reward sangat penting.

6. Value Function & Q-Value

Bagaimana agen tahu aksi mana yang bagus jika reward-nya baru datang belakangan? Jawabannya: agen memperkirakan nilai (value).

State-Value V(s)"Seberapa bagus berada di state s?" = rata-rata return yang diharapkan jika mulai dari s lalu mengikuti policy π.
Action-Value Q(s, a)"Seberapa bagus melakukan aksi a di state s?" = rata-rata return jika di s melakukan a, lalu mengikuti π.
Vπ(s) = 𝔼π[ Gt | st = s ]     Qπ(s,a) = 𝔼π[ Gt | st = s, at = a ]

Kalau kita tahu Q yang optimal (Q*), policy terbaik menjadi sangat mudah: di setiap state, pilih aksi dengan Q tertinggi.

π*(s) = argmaxa Q*(s, a)

Persamaan Bellman (intuisi)

Nilai sebuah state = reward langsung + nilai (terdiskon) state berikutnya. Ini hubungan rekursif yang menjadi fondasi hampir semua algoritma RL:

Q*(s,a) = 𝔼[ r + γ · maxa' Q*(s', a') ]
🗺️ Analogi Kamu di persimpangan dan tahu "dari persimpangan berikutnya, rumah tinggal 5 menit". Maka nilai jalan ini = waktu ke persimpangan berikutnya + 5 menit. Kamu tidak perlu menghitung seluruh rute dari nol — cukup gunakan estimasi dari langkah berikutnya.

✍️ Contoh hitung manual: nilai state di sebuah lorong

Lorong berisi 4 kotak: [S1] [S2] [S3] [S4] [🏆]. Setiap langkah bernilai −1, masuk 🏆 bernilai +10 (episode selesai), γ = 0.9, dan policy-nya selalu ke kanan. Pakai Bellman: V(s) = r + γ · V(s'), dihitung mundur dari tujuan:

  1. V(S4) = +10 (langsung masuk 🏆, tidak ada nilai sesudahnya) = 10
  2. V(S3) = −1 + 0.9 × V(S4) = −1 + 9 = 8
  3. V(S2) = −1 + 0.9 × V(S3) = −1 + 7.2 = 6.2
  4. V(S1) = −1 + 0.9 × V(S2) = −1 + 5.58 = 4.58

Makin jauh dari tujuan, makin kecil nilainya. Sekarang cek apakah "ke kanan" memang aksi terbaik di S3 dengan membandingkan nilai Q:

  • Q(S3, →) = −1 + 0.9 × V(S4) = −1 + 9 = 8
  • Q(S3, ←) = −1 + 0.9 × V(S2) = −1 + 5.58 = 4.58

Karena 8 > 4.58, aksi terbaik di S3 adalah →, sesuai rumus π*(s) = argmaxa Q(s,a). Angka 10, 8, 6.2, dan 4.58 ini akan muncul lagi persis di demo Value Iteration modul Intermediate.

7. Algoritma Q-Learning

Q-Learning (Watkins, 1989) adalah algoritma RL klasik yang mempelajari Q* langsung dari pengalaman, tanpa perlu tahu aturan lingkungan (model-free). Agen menyimpan sebuah Q-table: tabel berisi nilai Q untuk setiap pasangan (state, aksi).

Aturan update

Q(s,a) ← Q(s,a) + α · [ r + γ · maxa' Q(s',a') − Q(s,a) ]
  • Bagian hijau = TD target: estimasi baru yang "lebih tahu" karena sudah melihat reward nyata.
  • [ target − Q lama ] = TD error: seberapa meleset tebakan lama kita.
  • α (alpha, learning rate, 0–1) = seberapa besar kita menggeser tebakan ke arah target.

Contoh hitungan

Misalkan Q(s,a) = 2, agen dapat r = −1, di state berikutnya max Q(s',·) = 5, dengan γ = 0.9 dan α = 0.5:

  1. TD target = −1 + 0.9 × 5 = 3.5
  2. TD error = 3.5 − 2 = 1.5
  3. Q baru = 2 + 0.5 × 1.5 = 2.75 → tebakan bergeser mendekati target.

✍️ Contoh hitung manual: Q-Learning selama 3 episode

Supaya terlihat bagaimana agen belajar, kita lacak Q-table di lorong mini: [S0] [S1] [🏆]. Aksi: → (kanan) atau ← (kiri; di S0 menabrak dinding sehingga tetap di S0). Reward: masuk 🏆 = +10, langkah lain = −1. Parameter: α = 0.5, γ = 0.9, semua Q awal = 0. Anggap di setiap langkah agen memilih → (misalnya karena eksplorasi).

Ep.s, ars'TD target = r + γ·max Q(s',·)Q baru = Q lama + 0.5 × (target − Q lama)
1S0, →−1S1−1 + 0.9 × 0 = −10 + 0.5 × (−1 − 0) = −0.5
1S1, →+10🏆10 (terminal, tanpa bootstrap)0 + 0.5 × (10 − 0) = 5
2S0, →−1S1−1 + 0.9 × 5 = 3.5−0.5 + 0.5 × (3.5 + 0.5) = 1.5
2S1, →+10🏆105 + 0.5 × (10 − 5) = 7.5
3S0, →−1S1−1 + 0.9 × 7.5 = 5.751.5 + 0.5 × (5.75 − 1.5) = 3.625
3S1, →+10🏆107.5 + 0.5 × (10 − 7.5) = 8.75

Jika diteruskan, nilainya konvergen ke Q(S1, →) = 10 dan Q(S0, →) = −1 + 0.9 × 10 = 8, sama dengan hitungan Bellman di bagian 6.

🔍 Tiga pelajaran dari tabel ini
  • Reward merambat mundur. Di episode 1, S0 belum "tahu" ada hadiah (−0.5). Baru di episode 2 informasi +10 dari S1 sampai ke S0 lewat suku γ·max Q(s').
  • Eksplorasi itu penting. Setelah episode 1, Q(S0, →) = −0.5 lebih kecil dari Q(S0, ←) = 0. Agen yang 100% greedy justru akan memilih ← (menabrak dinding) dan bisa terjebak. Dengan ε-greedy, agen masih sesekali mencoba → lagi.
  • α mengatur kecepatan belajar. Setiap update hanya menggeser Q setengah jalan (α = 0.5) ke arah target, sehingga butuh beberapa episode untuk konvergen.

Langkah lengkap algoritma

  1. Inisialisasi Q-table dengan nol untuk semua (state, aksi).
  2. Untuk setiap episode: reset lingkungan, ambil state awal s.
  3. Pilih aksi a dengan ε-greedy berdasarkan Q-table.
  4. Lakukan aksi, amati reward r dan state baru s'.
  5. Update Q(s,a) dengan rumus di atas.
  6. s ← s'. Ulangi langkah 3–6 sampai episode selesai.
  7. (Opsional) Kurangi ε perlahan agar agen makin sering mengeksploitasi seiring waktu.

9. Implementasi Python

Kode berikut adalah versi Python dari demo di atas — hanya butuh numpy. Simpan sebagai q_learning.py lalu jalankan.

import numpy as np

# ---------- Lingkungan Gridworld 5x5 ----------
ROWS, COLS = 5, 5
START, GOAL = (4, 0), (0, 4)
HOLES = {(1, 1), (1, 3), (3, 2), (2, 4)}
MOVES = [(-1, 0), (0, 1), (1, 0), (0, -1)]  # atas, kanan, bawah, kiri

def step(state, action):
    r, c = state
    dr, dc = MOVES[action]
    nr = min(max(r + dr, 0), ROWS - 1)   # menabrak dinding = diam di tempat
    nc = min(max(c + dc, 0), COLS - 1)
    nxt = (nr, nc)
    if nxt == GOAL:  return nxt, 10, True
    if nxt in HOLES: return nxt, -10, True
    return nxt, -1, False

# ---------- Agen Q-Learning ----------
alpha, gamma, epsilon = 0.5, 0.9, 0.2
Q = np.zeros((ROWS, COLS, 4))        # Q-table: state (baris, kolom) x 4 aksi
rng = np.random.default_rng(0)

for episode in range(500):
    s, done, total = START, False, 0
    for _ in range(100):                  # batas langkah per episode
        # ε-greedy
        a = rng.integers(4) if rng.random() < epsilon else int(np.argmax(Q[s]))
        s2, r, done = step(s, a)
        # update Q-Learning
        target = r if done else r + gamma * np.max(Q[s2])
        Q[s][a] += alpha * (target - Q[s][a])
        s, total = s2, total + r
        if done: break
    epsilon = max(0.01, epsilon * 0.995)   # kurangi eksplorasi perlahan
    if (episode + 1) % 100 == 0:
        print(f"Episode {episode+1}: return = {total}")

# ---------- Tampilkan policy hasil belajar ----------
arrows = "↑→↓←"
for r in range(ROWS):
    row = ""
    for c in range(COLS):
        if (r, c) == GOAL:    row += " G "
        elif (r, c) in HOLES: row += " X "
        else: row += f" {arrows[np.argmax(Q[r, c])]} "
    print(row)

Kenapa return = 3? Jalur terpendek dari start ke 🏆 adalah 8 langkah: 7 langkah biasa (7 × −1) + langkah terakhir masuk tujuan (+10) = +3. Itu nilai maksimum yang mungkin — agen sudah menemukan jalur optimal.

  • RL = agen belajar dari reward lewat interaksi trial-and-error dengan lingkungan.
  • Tujuannya memaksimalkan return (reward kumulatif terdiskon γ), bukan reward sesaat.
  • Agen harus menyeimbangkan eksplorasi dan eksploitasi — ε-greedy adalah cara paling sederhana.
  • Masalah RL dirumuskan sebagai MDP (S, A, P, R, γ) yang memenuhi sifat Markov.
  • Q-Learning mempelajari Q(s,a) dengan update: Q ← Q + α(r + γ·max Q' − Q). Policy = pilih aksi dengan Q terbesar.
