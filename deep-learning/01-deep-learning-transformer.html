Deep Learning & Transformer

Dari satu neuron sampai GPT. Modul jembatan menuju RLHF dan LLM. Estimasi waktu belajar ± 4 jam.

🎯 Tujuan belajar Setelah modul ini kamu bisa: (1) menjelaskan cara neural network belajar (forward, loss, backprop, optimizer), (2) mendiagnosis masalah training seperti overfitting dan learning rate yang salah, (3) memahami self-attention dan blok transformer sampai ke rumusnya, (4) menjelaskan cara LLM menghasilkan teks, dan (5) membangun mini-GPT dari nol dengan PyTorch.
Prasyarat: Python, dasar NumPy, dan Matematika untuk RL (gradien, softmax, cross-entropy). Modul ini berdiri sendiri, tetapi juga menjadi fondasi untuk bagian DQN/PPO dan RLHF di modul RL Advanced.

1. Gambaran Besar

Deep learning adalah machine learning dengan neural network berlapis banyak yang mempelajari representasi data secara otomatis. Alih-alih merancang fitur dengan tangan ("deteksi tepi", "hitung kata"), jaringan menemukan sendiri fitur yang berguna dari data mentah: piksel, audio, atau teks.

1. ModelFungsi berparameter fθ(x). Contoh: MLP, CNN, transformer. θ bisa berjumlah ribuan sampai ratusan miliar.
2. LossAngka yang mengukur seberapa salah prediksi. Contoh: MSE, cross-entropy.
3. OptimizerCara memperbarui θ agar loss turun, berdasarkan gradien dari backpropagation. Contoh: SGD, Adam.
4. DataContoh untuk belajar. Kualitas dan jumlah data sering lebih menentukan daripada arsitektur.

Keempat komponen ini sama untuk semua model, dari klasifikasi gambar sederhana sampai GPT. Yang berubah hanya arsitektur, data, dan skalanya.

2. Neuron & MLP

Satu neuron menghitung jumlah tertimbang dari input, menambahkan bias, lalu melewatkannya ke fungsi aktivasi:

y = g( w1x1 + w2x2 + … + b ) = g( w⊤x + b )

Banyak neuron yang disusun sejajar membentuk layer, yang ditulis ringkas dalam bentuk matriks: h = g(Wx + b). Menumpuk beberapa layer menghasilkan Multi-Layer Perceptron (MLP):

ŷ = W3 · g( W2 · g( W1x + b1 ) + b2 ) + b3

Garis bergerak = sinyal mengalir maju (forward pass). Setiap garis adalah satu bobot w yang dipelajari.

✍️ Contoh hitung manual: satu neuron

Input x = (1; 2), bobot w = (0,5; 0,25), bias b = −0,5:

  1. Jumlah tertimbang: z = 0,5×1 + 0,25×2 + (−0,5) = 0,5 + 0,5 − 0,5 = 0,5
  2. Dengan aktivasi ReLU: max(0; 0,5) = 0,5. Dengan sigmoid: 1/(1 + e−0,5) = 0,622

Bobot menentukan seberapa penting tiap input, bias menggeser "ambang" kapan neuron aktif. Hanya itu yang dilakukan satu neuron. Kecerdasan muncul dari jutaan neuron yang bobotnya disetel bersama.

💡 Kenapa harus "deep"? Secara teori, MLP dengan satu hidden layer yang cukup lebar bisa mendekati fungsi kontinu apa pun (universal approximation theorem). Dalam praktik, jaringan yang lebih dalam jauh lebih efisien: layer awal belajar fitur sederhana, layer berikutnya menggabungkannya menjadi fitur yang makin abstrak.

3. Fungsi Aktivasi

Tanpa aktivasi non-linear, berapa pun banyaknya layer, hasilnya tetap fungsi linear, karena W2(W1x) = (W2W1)x. Non-linearitas inilah yang membuat jaringan bisa mempelajari pola rumit.

AktivasiKelebihanKekurangan / catatan
SigmoidOutput 0–1, cocok untuk peluangGradien hampir nol di ujung (vanishing gradient). Jarang dipakai di hidden layer.
TanhOutput −1 sampai 1, berpusat di nolMasih bisa jenuh. Default di PPO untuk jaringan kecil.
ReLUSangat murah, gradien tidak jenuh untuk x > 0Neuron bisa "mati" (selalu 0). Default untuk CNN dan MLP.
GELUVersi ReLU yang halusDipakai di BERT, GPT, dan kebanyakan transformer.

4. Loss Function

MSE (regresi)L = (1/N) Σ (y − ŷ)². Untuk memprediksi angka kontinu: harga, suhu, dan nilai V/Q pada critic dan DQN.
Cross-entropy (klasifikasi)L = −Σk yk log pk = −log pkelas benar. Untuk memilih satu dari K kelas, termasuk memprediksi token berikutnya di LLM.

Cross-entropy menghukum keras prediksi yang yakin tetapi salah: jika peluang kelas yang benar 0,9, loss = 0,105; jika 0,01, loss = 4,6. Pasangan softmax + cross-entropy memiliki gradien yang sangat sederhana terhadap logit:

∂L / ∂z = p − y    (peluang prediksi dikurangi one-hot label)

Bandingkan dengan gradien log-softmax di policy gradient (onehot − π). Itu rumus yang sama dengan tanda terbalik, karena policy gradient memaksimalkan, bukan meminimalkan. Melatih LLM dengan cross-entropy dan melatih policy dengan REINFORCE ternyata sangat mirip. Bedanya hanya pada bobot setiap contoh.

✍️ Contoh hitung manual: softmax + cross-entropy

Model mengklasifikasi gambar menjadi (kucing, anjing, burung) dengan logit (2; 1; 0). Label yang benar: kucing.

  1. ez = (7,389; 2,718; 1,000), totalnya 11,107
  2. Peluang p = (0,665; 0,245; 0,090)
  3. Loss = −ln pkucing = −ln 0,665 ≈ 0,408
  4. Gradien terhadap logit: p − y = (0,665 − 1; 0,245 − 0; 0,090 − 0) = (−0,335; 0,245; 0,090)

Gradient descent mengurangi logit dengan gradien ini: logit kucing naik (karena gradiennya negatif), logit anjing dan burung turun. Persis yang kita inginkan.

5. Backpropagation & Optimizer

Backpropagation menghitung gradien loss terhadap semua parameter dengan aturan rantai, mulai dari output mundur ke input. Setiap operasi cukup tahu turunan lokalnya sendiri. Contoh dengan satu neuron, ŷ = wx + b dan L = (ŷ − y)²:

  1. Forward: x = 2, w = 0,5, b = 1 → ŷ = 2. Target y = 3 → L = (2 − 3)² = 1.
  2. Backward: ∂L/∂ŷ = 2(ŷ − y) = −2. Lalu ∂L/∂w = −2 · x = −4 dan ∂L/∂b = −2 · 1 = −2.
  3. Update (α = 0,1): w ← 0,5 + 0,4 = 0,9, b ← 1 + 0,2 = 1,2. Sekarang ŷ = 3,0 dan loss turun ke 0.

✍️ Hitung manual: backprop pada jaringan 2 layer

Jaringan kecil: 2 input → 2 neuron tersembunyi (ReLU) → 1 output, dengan loss L = (ŷ − y)². Data: x = (1; 2), target y = 2. Bobot awal: neuron 1 punya w = (0,5; −0,5), neuron 2 punya w = (0,25; 0,5), layer output v = (1,0; 0,8), semua bias 0.

Forward (maju):

TahapNeuron 1Neuron 2
z = w · x0,5×1 + (−0,5)×2 = −0,50,25×1 + 0,5×2 = 1,25
h = ReLU(z)0 (mati)1,25

Output: ŷ = 1,0×0 + 0,8×1,25 = 1,0. Loss = (1 − 2)² = 1.

Backward (mundur), dengan aturan rantai:

  1. ∂L/∂ŷ = 2(ŷ − y) = 2(1 − 2) = −2
  2. Bobot output: ∂L/∂v = −2 × h = −2 × (0; 1,25) = (0; −2,5), dan ∂L/∂biasout = −2
  3. Mundur ke neuron tersembunyi: ∂L/∂h = −2 × v = (−2; −1,6)
  4. Melewati ReLU: neuron 1 mati (z < 0), turunan ReLU = 0, sehingga gradiennya 0. Neuron 2 aktif, turunan = 1, sehingga gradiennya tetap −1,6.
  5. Bobot neuron 2: ∂L/∂w = −1,6 × x = −1,6 × (1; 2) = (−1,6; −3,2). Bobot neuron 1: (0; 0), tidak belajar apa pun dari contoh ini (dead ReLU).

Update dengan learning rate 0,1 (bobot baru = bobot − 0,1 × gradien):

  • v = (1,0; 0,8) − 0,1×(0; −2,5) = (1,0; 1,05), biasout = 0 − 0,1×(−2) = 0,2
  • wneuron 2 = (0,25; 0,5) − 0,1×(−1,6; −3,2) = (0,41; 0,82)
  • Forward ulang: h2 = 0,41 + 0,82×2 = 2,05, sehingga ŷ = 1,05×2,05 + 0,2 = 2,3525. Loss baru = 0,3525² ≈ 0,124 (turun dari 1).

Semua angka gradien di atas sudah dicocokkan dengan loss.backward() PyTorch dan hasilnya identik. Prediksi sekarang sedikit kebablasan (2,35 > 2). Itulah pentingnya memilih learning rate.

6. Training yang Sehat

Tujuan sebenarnya bukan loss kecil di data latih, melainkan generalisasi: bekerja baik di data yang belum pernah dilihat. Selalu pisahkan data menjadi train / validation / test.

GejalaDiagnosisSolusi umum
Train loss turun, val loss naikOverfitting (menghafal)Tambah data, augmentasi, weight decay, dropout, early stopping
Train loss tetap tinggiUnderfittingModel lebih besar, latih lebih lama, cek bug data/label
Loss melonjak atau NaNLearning rate terlalu besar, gradien meledakTurunkan lr, gradient clipping, warmup, cek normalisasi input
Loss turun sangat lambatlr terlalu kecil, inisialisasi burukNaikkan lr, pakai Adam, normalisasi
NormalisasiBatchNorm (CNN) dan LayerNorm (transformer) menjaga skala aktivasi tetap stabil di setiap layer, sehingga training lebih cepat dan stabil.
Residual connectionx + f(x): gradien punya "jalan tol" langsung ke layer awal. Inilah yang memungkinkan jaringan ratusan layer (ResNet, transformer).
RegularisasiWeight decay menjaga bobot tetap kecil. Dropout mematikan neuron secara acak saat training agar jaringan tidak bergantung pada satu jalur.
Tips pertamaSebelum melatih penuh, coba overfit satu batch kecil sampai loss ≈ 0. Kalau tidak bisa, hampir pasti ada bug.

7. CNN, RNN & Masalahnya

CNN (Convolutional NN)Filter kecil yang digeser di seluruh gambar dengan bobot yang dibagi (weight sharing). Efisien untuk data grid seperti gambar. DQN Atari memakai 3 layer CNN untuk membaca layar.
RNN / LSTMMemproses urutan satu elemen per langkah dengan "memori" ht = f(ht−1, xt). Dulu menjadi standar untuk teks dan suara.

RNN punya dua masalah besar yang mendorong lahirnya transformer:

  • Sulit mengingat jauh: informasi dari kata ke-1 harus melewati puluhan langkah untuk sampai ke kata ke-50, dan gradiennya mengecil di setiap langkah (vanishing gradient).
  • Tidak bisa diparalelkan: langkah t harus menunggu langkah t−1, sehingga tidak memanfaatkan GPU secara optimal.

Transformer menyelesaikan keduanya dengan attention: setiap token bisa langsung "melihat" token mana pun dalam satu langkah, dan semua posisi dihitung paralel.

8. Tokenisasi & Embedding

Neural network hanya memproses angka. Teks diubah menjadi angka dalam dua tahap:

Tokenisasi

Teks dipotong menjadi token, biasanya potongan kata (subword) hasil algoritma seperti BPE (Byte Pair Encoding). Kata umum menjadi satu token, sedangkan kata langka dipecah. Setiap token punya ID di dalam kosakata (biasanya 30 ribu–200 ribu token). Contoh ilustrasi:

"Pem""belajar""an"" mesin"" itu"" menyenangkan""!"

Pemotongan persisnya bergantung pada tokenizer masing-masing model. Bahasa yang jarang muncul di data latih (termasuk bahasa Indonesia) cenderung dipecah menjadi lebih banyak token per kata dibanding bahasa Inggris.

Embedding

Setiap ID token dipetakan ke sebuah vektor berdimensi d (misalnya 768) lewat tabel yang dipelajari. Token dengan makna mirip akan memiliki vektor yang berdekatan, sehingga kemiripannya bisa diukur dengan dot product atau cosine similarity.

✍️ Contoh hitung manual (embedding 3 dimensi buatan): kucing = (0,9; 0,8; 0,1), anjing = (0,8; 0,9; 0,2), mobil = (0,1; 0,2; 0,9). Cosine similarity = (a · b) / (|a| × |b|):

  • kucing · anjing = 0,72 + 0,72 + 0,02 = 1,46. |kucing| = √(0,81 + 0,64 + 0,01) = 1,208 dan |anjing| = 1,221. Cosine = 1,46 / (1,208 × 1,221) ≈ 0,99 (sangat mirip)
  • kucing · mobil = 0,09 + 0,16 + 0,09 = 0,34. |mobil| = √(0,01 + 0,04 + 0,81) = 0,927. Cosine = 0,34 / (1,208 × 0,927) ≈ 0,30 (tidak mirip)

Informasi posisi

Attention sendiri tidak tahu urutan: "anjing menggigit orang" dan "orang menggigit anjing" berisi token yang sama. Karena itu ditambahkan positional encoding: embedding posisi yang dipelajari (GPT-2), fungsi sinusoidal (transformer asli), atau RoPE yang memutar vektor sesuai posisinya (LLaMA dan banyak LLM modern).

9. Self-Attention

Ide utamanya: untuk memahami sebuah token, kumpulkan informasi dari token lain yang relevan. Setiap token membuat tiga vektor dari embedding-nya:

Query (Q)"Informasi apa yang sedang saya cari?"
Key (K)"Informasi apa yang saya tawarkan?"
Value (V)"Ini isi yang akan saya berikan jika dipilih."
🏛️ Penjelasan untuk awam: kenapa attention dibutuhkan? Arti sebuah kata sering bergantung pada kata lain. Bandingkan "Ular itu punya bisa" dengan "Saya bisa berenang". Kata "bisa"-nya sama persis, tetapi artinya (racun vs mampu) baru jelas setelah melihat kata "ular" atau "saya". Begitu juga kata "lapar" dalam "Kucing itu lapar": kata itu sendiri tidak tahu siapa yang lapar. Attention adalah mekanisme agar setiap kata bisa "menengok" kata lain dan mengambil informasi yang ia butuhkan.

Analogi perpustakaan:
  • Query = pertanyaan yang kamu bawa ke perpustakaan ("saya cari buku tentang hewan").
  • Key = label di punggung setiap buku ("hewan", "masakan", "sejarah").
  • Skor = seberapa cocok pertanyaanmu dengan setiap label, yaitu dot product Q·K.
  • Softmax = membagi waktu bacamu: 77% untuk buku yang paling cocok, sisanya untuk buku lain.
  • Value = isi buku. Output = rangkuman campuran isi buku sesuai porsi waktu baca tadi.
Bedanya dengan perpustakaan sungguhan: di attention, setiap kata sekaligus menjadi pengunjung (punya Query) dan buku (punya Key dan Value).

Q, K, V didapat dari perkalian matriks yang dipelajari: Q = XWQ, K = XWK, V = XWV. Lalu:

Attention(Q, K, V) = softmax( QK⊤ / √dk ) · V
  1. QK⊤: skor kecocokan (dot product) setiap pasangan token, membentuk matriks T×T.
  2. Bagi dengan √dk agar skor tidak terlalu besar. Tanpa ini, softmax menjadi terlalu "tajam" dan gradiennya mengecil.
  3. Softmax per baris: setiap token membagi 100% perhatiannya ke token lain.
  4. Kalikan dengan V: output setiap token = rata-rata tertimbang Value dari token yang diperhatikannya.

✍️ Hitung manual lengkap: attention untuk "Kucing itu lapar"

Kita hitung semuanya dengan tangan untuk kalimat 3 token. Agar angkanya kecil, setiap token hanya punya 2 angka (model sungguhan punya ratusan sampai ribuan). Anggap angka pertama berarti "seberapa benda" dan angka kedua "seberapa sifat/keadaan". Semua bobot di contoh ini dibuat tangan agar mudah diikuti. Di model sungguhan, bobot itu dipelajari dari data.

Langkah 1: hitung Q, K, V dengan mengalikan x dengan tiga matriks bobot:

  • WQ = [[0 1] [1 0]] artinya menukar kedua angka. Maknanya: "kata sifat mencari benda, kata benda mencari sifatnya".
  • WK = WV = [[1 0] [0 1]] (matriks identitas), sehingga K = V = x. Ini sengaja dibuat sederhana.

Contoh perkalian untuk Query "lapar": vektor baris (0; 2) dikali kolom-kolom WQ: angka ke-1 = 0×0 + 2×1 = 2, angka ke-2 = 0×1 + 2×0 = 0, sehingga Qlapar = (2; 0). Artinya "lapar" sedang mencari sesuatu yang bersifat benda.

Dengan causal mask, token hanya boleh melihat dirinya dan token sebelumnya, karena saat menulis teks, kata berikutnya memang belum ada. Matikan "bagi dengan √d" untuk melihat distribusi yang lebih tajam.

Multi-head attention

Satu "kepala" attention hanya bisa menangkap satu jenis hubungan. Multi-head attention menjalankan h attention paralel dengan proyeksi berbeda (misalnya satu kepala melacak subjek–kata kerja, kepala lain melacak kata ganti), lalu menggabungkan hasilnya. GPT-2 small memakai 12 kepala per layer.

✍️ Hitung manual: kenapa harus dibagi √dk?

Di GPT-2, setiap kepala memakai dk = 64. Dot product dari dua vektor acak berdimensi 64 (isi sekitar ±1) adalah jumlah 64 perkalian kecil, sehingga besarnya biasanya sekitar √64 = 8. Bandingkan softmax dua skor:

  • Tanpa pembagian, skor (8; 0): softmax = (0,9997; 0,0003). Hampir seluruh perhatian ke satu token, dan gradien untuk token lain nyaris 0, sehingga model sulit belajar.
  • Dibagi √64 = 8, skor menjadi (1; 0): softmax = (0,731; 0,269). Masih ada preferensi, tetapi tidak ekstrem, sehingga gradien tetap mengalir.

✍️ Hitung manual: multi-head dengan angka

  1. Misalkan vektor sebuah token punya 4 angka: (1,0; 0,5; −0,2; 0,8). Dengan 2 kepala, vektor ini dipotong dua: kepala 1 mendapat (1,0; 0,5), kepala 2 mendapat (−0,2; 0,8).
  2. Masing-masing kepala menjalankan langkah 1–5 di atas secara terpisah, dengan WQ, WK, WV sendiri. Kepala 1 mungkin belajar "cari subjek", kepala 2 "cari kata sebelumnya".
  3. Output kedua kepala (masing-masing 2 angka) disambung kembali menjadi 4 angka, lalu dikalikan matriks WO untuk mencampur hasil semua kepala.
  4. Di GPT-2 small: d = 768 dibagi 12 kepala = 64 angka per kepala, sehingga pembaginya √64 = 8.
⚠️ Biaya attention Untuk T token, ada T × T skor yang harus dihitung. Kalimat 3 token di atas butuh 9 skor. Teks 1000 token butuh 1.000.000 skor per kepala per layer, dan 100.000 token butuh 10 miliar. Inilah alasan konteks panjang mahal dan butuh trik seperti FlashAttention dan KV cache.

10. Blok Transformer

Satu blok transformer (versi decoder ala GPT dengan pre-LayerNorm) terdiri dari dua sub-layer, masing-masing dibungkus residual connection:

  • Attention = token saling bertukar informasi ("komunikasi").
  • Feed-forward = setiap token memproses informasi yang sudah dikumpulkan secara terpisah ("komputasi"). Sebagian besar parameter ada di sini.
  • Satu blok punya sekitar 12d² parameter (4d² attention + 8d² FFN). GPT-2 small (d = 768, 12 blok) ≈ 85 juta di blok + 38 juta embedding ≈ 124 juta.
👥 Penjelasan untuk awam: satu blok transformer seperti satu putaran rapat
  • Attention = sesi diskusi: setiap peserta (token) mendengarkan peserta lain yang relevan dan mencatat informasi penting.
  • Residual (+) = catatan pribadi tidak dibuang. Hasil diskusi hanya ditambahkan ke catatan awal, sehingga informasi asli tidak hilang.
  • LayerNorm = moderator yang menyamakan "volume suara" agar tidak ada angka yang terlalu besar atau terlalu kecil.
  • Feed-forward = setiap peserta merenung sendiri memakai pengetahuannya. Banyak "hafalan fakta" model diduga tersimpan di sini.
  • Banyak blok = beberapa putaran rapat. Putaran awal menangkap hal sederhana (tata bahasa), putaran akhir menangkap makna yang lebih abstrak.

✍️ Hitung manual lengkap: dari "lapar" sampai prediksi kata berikutnya

Kita lanjutkan contoh "Kucing itu lapar" dari bagian 9. Model harus menebak kata sesudah "lapar", jadi kita ikuti vektor token terakhir, xlapar = (0; 2), melewati satu blok.

Penyederhanaan: di model sungguhan ada LayerNorm sebelum attention dan sebelum FFN (pre-LN). Di sini LayerNorm dilewati agar angkanya mudah diikuti, lalu cara kerjanya dihitung terpisah di langkah 3. Untuk vektor 2 angka, LayerNorm selalu menghasilkan (−1; +1), sehingga kurang menarik sebagai contoh.

Langkah 1: attention (sudah dihitung di bagian 9): output attention untuk "lapar" = (1,723; 0,277).

Langkah 2: residual pertama, yaitu jumlahkan input dan output attention:

h = x + Attention(x) = (0; 2) + (1,723; 0,277) = (1,723; 2,277)

Angka kedua (sifat: "lapar") tetap ada, dan angka pertama sekarang berisi informasi "benda/kucing" dari attention. Tanpa residual, makna asli "lapar" bisa hilang.

Langkah 3: cara kerja LayerNorm (contoh vektor 4 angka (2; 4; 6; 8)):

  1. Rata-rata: (2 + 4 + 6 + 8)/4 = 5
  2. Variansi: ((−3)² + (−1)² + 1² + 3²)/4 = (9 + 1 + 1 + 9)/4 = 5, sehingga standar deviasi = √5 ≈ 2,236
  3. Normalisasi (x − rata-rata)/std: (−3; −1; 1; 3)/2,236 = (−1,342; −0,447; 0,447; 1,342)
  4. Terakhir dikali skala γ dan ditambah geser β yang dipelajari (awalnya γ = 1, β = 0).

Apa pun skala inputnya (misalnya (200; 400; 600; 800)), hasilnya tetap sama. Inilah yang membuat training puluhan layer tetap stabil.

Langkah 4: feed-forward (FFN). Vektor diperlebar 2 → 4 angka, diberi ReLU, lalu dikecilkan lagi 4 → 2 (di GPT: 768 → 3072 → 768). Bobotnya (dibuat tangan): W1 = [[1 −1 0,5 0] [0 1 0,5 −1]] dan W2 = [[0,5 0] [0 0,5] [0,2 0,2] [1 1]].

  1. h × W1: (1,723×1 + 2,277×0; 1,723×(−1) + 2,277×1; 1,723×0,5 + 2,277×0,5; 1,723×0 + 2,277×(−1)) = (1,723; 0,554; 2,000; −2,277)
  2. ReLU (negatif menjadi 0): (1,723; 0,554; 2,000; 0). Neuron ke-4 "tidak menyala".
  3. × W2: angka ke-1 = 1,723×0,5 + 0,554×0 + 2×0,2 + 0×1 = 1,262; angka ke-2 = 1,723×0 + 0,554×0,5 + 2×0,2 + 0×1 = 0,677, sehingga FFN(h) = (1,262; 0,677)

Langkah 5: residual kedua: h₂ = h + FFN(h) = (1,723; 2,277) + (1,262; 0,677) = (2,985; 2,954). Inilah output satu blok. Di GPT-2, vektor ini masuk lagi ke blok berikutnya, dan seterusnya sampai 12 kali.

Langkah 6: ubah menjadi peluang kata berikutnya. Misalkan kosakata kita hanya 3 kata: "sekali", "dan", ".". Kalikan dengan matriks output Wout = [[1 0 0,5] [0,5 1 0]] untuk mendapat satu skor (logit) per kata:

KataLogitelogitPeluang
"sekali"2,985×1 + 2,954×0,5 = 4,46286,686,6/110,2 = 78,6%
"dan"2,985×0 + 2,954×1 = 2,95419,219,2/110,2 = 17,4%
"."2,985×0,5 + 2,954×0 = 1,4924,44,4/110,2 = 4,0%

Model menebak "Kucing itu lapar sekali" dengan keyakinan 78,6%.

Langkah 7: loss saat training. Jika kata yang benar di data memang "sekali", cross-entropy = −ln 0,786 ≈ 0,241 (kecil = tebakan bagus). Jika yang benar ternyata ".", loss = −ln 0,040 ≈ 3,2, dan backprop akan mengubah semua bobot di langkah 1–6 (WQ, WK, WV, W1, W2, Wout, dan embedding) agar lain kali peluang "." naik. Seluruh proses ini diulang miliaran kali pada teks sungguhan.

11. Language Model & Sampling

LLM decoder-only dilatih dengan tugas yang sangat sederhana: prediksi token berikutnya. Untuk setiap posisi t, loss-nya adalah cross-entropy:

L = −(1/T) Σt log pθ( xt+1 | x1, …, xt )

Berkat causal mask, satu kalimat sepanjang T token memberikan T contoh latihan sekaligus. Saat dipakai, model menghasilkan teks secara autoregresif: prediksi distribusi token berikutnya → ambil satu token → tambahkan ke input → ulangi.

Demo: strategi sampling

Prompt: "Saya suka makan …". Logit model (contoh): nasi 3,0 · bakso 2,6 · sate 2,2 · buah 1,5 · pizza 1,0 · batu −1,0 · meja −2,0.

Temperatur rendah → jawaban konsisten dan aman. Temperatur tinggi → kreatif tetapi bisa ngawur ("batu"). top-k hanya menyimpan k kandidat teratas. top-p (nucleus) menyimpan kandidat terkecil yang total peluangnya ≥ p. Token yang dicoret tidak akan pernah dipilih. Temperatur → 0 sama dengan greedy decoding.

Dengan temperatur 0,5, semua logit dibagi 0,5 (nasi 6,0, bakso 5,2, …), sehingga peluang nasi naik menjadi 0,581 dan "batu" turun menjadi hampir 0.

Dari model bahasa menjadi asisten

  1. Pretraining: prediksi token berikutnya pada triliunan token teks internet dan buku. Model belajar bahasa, fakta, dan pola penalaran. Scaling laws menunjukkan loss turun secara teratur seiring bertambahnya parameter, data, dan komputasi (Chinchilla: ± 20 token data per parameter).
  2. Supervised fine-tuning (SFT): latih lanjut dengan contoh percakapan berkualitas. Teknik hemat seperti LoRA hanya melatih matriks kecil tambahan, bukan seluruh bobot.
  3. RLHF / DPO / RLVR: perlakukan LLM sebagai policy (state = teks sejauh ini, aksi = token berikutnya) dan optimalkan dengan reward. Semua ini dibahas di bagian 9 modul RL Advanced.
⚡ Detail efisiensi saat inferensi KV cache: Key dan Value token sebelumnya disimpan agar tidak dihitung ulang setiap kali token baru dibuat. Biaya attention tumbuh kuadratik terhadap panjang konteks (T²), sehingga konteks panjang butuh trik seperti FlashAttention.

12. Implementasi: Mini-GPT

a. Self-attention dalam beberapa baris

Implementasi rumus attention secara manual, lalu dicek dengan fungsi bawaan PyTorch. Install: pip install torch.

import torch
import torch.nn.functional as F

torch.manual_seed(0)
T, d = 5, 8                                   # 5 token, dimensi 8
x = torch.randn(T, d)                         # embedding token
Wq, Wk, Wv = (torch.randn(d, d) / d**0.5 for _ in range(3))
Q, K, V = x @ Wq, x @ Wk, x @ Wv

scores = Q @ K.T / d**0.5                     # (T, T) skor kecocokan
mask = torch.triu(torch.ones(T, T, dtype=torch.bool), diagonal=1)
scores = scores.masked_fill(mask, float("-inf"))   # causal: tidak boleh melihat masa depan
weights = F.softmax(scores, dim=-1)           # tiap baris berjumlah 1
out = weights @ V                             # (T, d)

print(weights.round(decimals=2))
ref = F.scaled_dot_product_attention(Q[None], K[None], V[None], is_causal=True)[0]
print("Sama dengan PyTorch?", torch.allclose(out, ref, atol=1e-6))

b. Mini-GPT dari nol

Transformer decoder level karakter yang lengkap: embedding, positional embedding, blok dengan masked multi-head attention + FFN + residual + LayerNorm, cross-entropy loss, dan generasi autoregresif. Datanya adalah kalimat bahasa Indonesia buatan dari pola sederhana, sehingga kita bisa melihat apakah model berhasil mempelajari struktur kalimat. Training ± 3 menit di CPU.

import random
import torch, torch.nn as nn, torch.nn.functional as F

# ---------- 1) Data: kalimat buatan dengan pola subjek-predikat-objek-keterangan ----------
random.seed(0); torch.manual_seed(0)
subjek = ["kucing", "anjing", "burung", "robot", "agen", "anak"]
kerja = ["melihat", "mengejar", "mencari", "membawa", "menyukai"]
objek = ["bola", "ikan", "makanan", "reward", "mainan", "bunga"]
tempat = ["di taman", "di rumah", "di pasar", "di sekolah", "di jalan"]
waktu = ["pagi ini", "kemarin", "setiap hari", "nanti malam"]

def kalimat():
    s = f"{random.choice(subjek)} itu {random.choice(kerja)} {random.choice(objek)} {random.choice(tempat)}"
    if random.random() < 0.5:
        s += " " + random.choice(waktu)
    return s + "."

teks = "\n".join(kalimat() for _ in range(2000))
chars = sorted(set(teks))
stoi = {c: i for i, c in enumerate(chars)}
encode = lambda s: [stoi[c] for c in s]
decode = lambda ids: "".join(chars[i] for i in ids)
data = torch.tensor(encode(teks))
n = int(0.9 * len(data))
train_data, val_data = data[:n], data[n:]

VOCAB, T, D, H, L = len(chars), 64, 96, 4, 3   # kosakata, konteks, dimensi, head, layer

def get_batch(split, B=32):
    d = train_data if split == "train" else val_data
    i = torch.randint(len(d) - T - 1, (B,))
    x = torch.stack([d[j:j + T] for j in i])
    y = torch.stack([d[j + 1:j + T + 1] for j in i])          # target = geser 1 karakter
    return x, y

# ---------- 2) Model ----------
class Block(nn.Module):
    def __init__(self):
        super().__init__()
        self.ln1, self.ln2 = nn.LayerNorm(D), nn.LayerNorm(D)
        self.attn = nn.MultiheadAttention(D, H, batch_first=True)
        self.ffn = nn.Sequential(nn.Linear(D, 4 * D), nn.GELU(), nn.Linear(4 * D, D))

    def forward(self, x):
        t = x.size(1)
        mask = torch.triu(torch.ones(t, t, dtype=torch.bool), diagonal=1)   # causal mask
        h = self.ln1(x)
        x = x + self.attn(h, h, h, attn_mask=mask, need_weights=False)[0]  # residual 1
        return x + self.ffn(self.ln2(x))                                    # residual 2

class MiniGPT(nn.Module):
    def __init__(self):
        super().__init__()
        self.tok, self.pos = nn.Embedding(VOCAB, D), nn.Embedding(T, D)
        self.blocks = nn.Sequential(*[Block() for _ in range(L)])
        self.ln, self.head = nn.LayerNorm(D), nn.Linear(D, VOCAB)

    def forward(self, idx, targets=None):
        x = self.tok(idx) + self.pos(torch.arange(idx.size(1)))
        logits = self.head(self.ln(self.blocks(x)))
        if targets is None:
            return logits, None
        return logits, F.cross_entropy(logits.view(-1, VOCAB), targets.view(-1))

    @torch.no_grad()
    def generate(self, idx, n, temperature=0.8):
        for _ in range(n):
            logits, _ = self(idx[:, -T:])
            probs = F.softmax(logits[:, -1] / temperature, dim=-1)
            idx = torch.cat([idx, torch.multinomial(probs, 1)], dim=1)   # autoregresif
        return idx

# ---------- 3) Training ----------
model = MiniGPT()
print(f"Parameter: {sum(p.numel() for p in model.parameters()):,} | kosakata: {VOCAB} karakter")
opt = torch.optim.AdamW(model.parameters(), lr=1e-3)

@torch.no_grad()
def eval_loss(split):
    return sum(model(*get_batch(split))[1].item() for _ in range(20)) / 20

for step in range(2001):
    _, loss = model(*get_batch("train"))
    opt.zero_grad(); loss.backward(); opt.step()
    if step % 400 == 0:
        print(f"langkah {step:4d} | loss train {eval_loss('train'):.3f} | loss val {eval_loss('val'):.3f}")

# ---------- 4) Generasi ----------
awal = torch.tensor([encode("robot")])
print("\n" + decode(model.generate(awal, 200)[0].tolist()))

📝 Membaca hasilnya
  • Loss awal ≈ ln(kosakata), yaitu tebakan acak seragam. Loss kemudian turun drastis saat model mempelajari ejaan kata, lalu struktur kalimat.
  • Loss tidak bisa mendekati 0 karena data memang acak: setelah "kucing itu", ada 5 kata kerja yang sama mungkin. Batas bawahnya adalah entropi data itu sendiri.

  • Perhatikan kesalahan "mainanan". Model memprediksi per karakter dan masih sangat kecil, sehingga sesekali "tergelincir". LLM sungguhan memakai token subword, jauh lebih banyak parameter, dan data yang jauh lebih besar.
